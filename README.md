## 1. 문제

지방소멸대응기금은 3년간 1,290억 원이 배분됐지만, 성과는 주로 집행률로만 평가됩니다. 집행률은 2022년 73.8%에서 2024년 40.9%로 떨어졌고, 집행률이 높다고 청년 유출이 줄어드는 것도 아닙니다.
기금이 청년 이동과 어떻게 연결되는지 검증하고, 담당자가 그 근거로 투자계획을 세울 수 있게 돕는 것을 목표로 했습니다.

## 2. 데이터

| 데이터 | 출처 | 범위 |
|---|---|---|
| 시군 월별 패널 (청년 순이동, 인구, 고령화, 고용보험) | 공공 통계 | 충북 11개 시군, 2017.01 ~ 2024.12, 1,056행 |
| 지방소멸대응기금 배분·집행 현황 | 공개 API | 2022 ~ 2024 |
| 사업 근거 문서 | 투자계획 관련 지침·사례 | - |

## 3. 접근

- **성과 지표**: 집행률 대신 20~39세 청년 순이동률
- **분석**: 지원 지역 6곳과 비교 지역 5곳의 정책 도입(2022.01) 전후를 비교하는 이중차분(DID), 평행추세·와일드 부트스트랩 등으로 강건성 점검
- **서비스 구조**: 숫자는 분석 엔진(Layer 1)이 계산하고, LLM 에이전트(Layer 2)는 질문 해석과 설명만 맡음. 답변의 모든 수치를 엔진 결과와 대조해 검증되지 않은 숫자는 폐기

## 4. 내 역할

위 흐름 중 다음을 맡았습니다.

- 기금 집행 데이터 EDA (집행률과 성과의 관계)
- DID 진단 결과(강건성·평행추세)를 에이전트 답변에 연결
- 질문 분류 오류 수정, 골든셋 기반 답변 평가 도입
- 지역 간 기금 비교 기능 구현
- 웹 화면 개선 (모바일 헤더, 첫 화면 예시 질문, 제안 페이지)

DID 분석, 서버·배포, 웹 화면 초기 제작은 다른 팀원이 맡았습니다.

## 6. 한계

- 사업별 예산과 착수월 자료가 없어 사업 유형별 효과는 확인하지 못했습니다.
- 시군이 11곳뿐이라 추정이 불안정하고, 배분 시점과 실제 집행 시점에 차이가 있습니다.
- 그래서 추천을 인과적 최적안으로 표현하지 않고, 최종 판단은 담당자에게 남기도록 설계했습니다.
